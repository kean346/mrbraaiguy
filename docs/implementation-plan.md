# Ember Glass delivery plan

Isolated project: `/workspace/ember-glass`. Public website and `/workspace/mrbraaiguy` remain outside the implementation scope.

## A — Evidence, foundations and design

Complete original-source reconciliation first. Establish DESIGN.md and UX-CONTRACT.md using installed frontend-design and frontend-design-premium skills. Resolve shared component ownership before screens. Inspect maintained library documentation and choose supported Next.js, strict TypeScript, MongoDB official driver, authentication, constrained rich-text and PDF dependencies. Define owner-only access, sessions, validation, indexes and immutable quote versions. Design responsive Proposal / Internal Costing workspaces and a distinct light A4 document system.

## B — Functional core

Implement and test pure decimal-safe pricing with explicit inclusive/exclusive tax, item states, markup versus margin, deposits and configurable policies. Implement persistent clients, menu templates, drafts and costing. Applying a suggested price must be explicit and audited. Build customer-safe document projection, preview and multipage PDF from the same issued snapshot; persist historical PDFs unchanged. Implement concurrent reference allocation, revisions, duplication, dashboard and audit trail. Authorisation applies to every server operation and download.

Acceptance gates: persistent reload journey; quick quote without costs; detailed costing; 40 × R790 inclusive fixture; independent ex-VAT fixture; billable versus included extras; adults/children; tax/deposit rounding; bundled travel protection; immutable versions; concurrent references; private-data leakage checks; malicious rich-text and unauthorised access tests.

## C — Operations

Reviewable Zoho CSV mapping, duplicate handling, provenance and opt-out preservation. Manual download/message workflow is the initial communication path. Sending integrations and campaigns remain visibly unconfigured until provider, authentication and explicit authorisation are verified.

## D — Verification and polish

Production build, typecheck, lint, domain and MongoDB integration suites, browser end-to-end journey, desktop/tablet/mobile screenshots, keyboard and contrast checks, long PDF inspection, security review and backup/restore evidence. Deliver synthetic sample PDF, setup guide, secret-free environment example and precise working/requires-integration/future checklist. Optional shopping list and shortcuts follow the core.

## Requested model routing

The user requests Astra for source analysis, complete design, MongoDB/authentication, PDF and final review; Sol for forms/menus and testing. Route delegated stages accordingly when implementation begins. No delegated implementation has run yet.

## Current status

Milestone A reconciliation and Milestone B local app are implemented. See `docs/source-reconciliation.md`, `README.md`, and `docs/test-evidence.md` for verified scope and remaining external decisions. Milestone C integrations remain unconfigured.
